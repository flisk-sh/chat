# Security Policy

## Reporting Security Issues

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

To report a vulnerability:
- Submit a draft security advisory via [GitHub Security Advisories](https://github.com/flisk-sh/chat/security/advisories/new).
- Alternatively, contact the maintainers directly at security@flisk.si.

Include detailed reproduction steps, potential impact, and any affected configurations. Reports are acknowledged within 48 hours.

## Supported Versions

Only the latest commit on `main` branch is actively supported with security updates.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |
| older commits    | :x:                |
